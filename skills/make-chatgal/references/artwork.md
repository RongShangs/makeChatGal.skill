# 素材与提示词

## 路由

有可用、授权的生图工具就正常调用；参考、编辑、透明输出按工具规则操作。没有工具时给完整逐图提示词、目标路径和待补清单，同时完成故事 JSON；不拿程序画的占位角色、随机网络图或成功声明冒充成品。

资源计划记录 `id/role/path/character/state/emotion/transparent/prompt/negativePrompt/referenceRole`，不适用的项可省略。脚本只产生清单和提示词，不执行生图；agent 应结合用户外形与风格改写，不把模板向导当固定人设。

## 画面要求

- 角色固定外形、比例、配色、面部、耳尾、配件和服装；每张只改变需要的表情/动作。参考图标明是形象参考还是编辑目标。
- 立绘为真透明 PNG，完整头发、耳尾、手脚和透明留边；统一视角与大小，无文字水印。白衣/白发属于主体，不能删除所有白色来抠图。
- 背景清楚交代地点、时段和光线，通常不画重复角色。事件 CG 服务当下剧情，文字由 slides 展示，不烧进图里。
- 主页按目标版本 cover 裁切与标题/抽屉安全区排主体；检查手机裁切后的脸与轮廓，避免宽横图角色挤在最右侧。
- 图集必须完整人物和分隔；按真实边界框切图，不盲信等分格。统一画布、人物缩放和脚底。`crop_sprites.py` 接受检查过的边界框，不猜主体或重绘。

## 无生图工具时

交付 `asset-plan.json`、`IMAGE_PROMPTS.md`、每张图的独立提示词、源包和缺图列表；说明结果应保存的路径。可使用用户授权的现成素材并记录来源。补齐后才运行正式打包。

不要强迫所有 agent 安装某供应商 SDK 或购买服务。服务须由用户明确选择或已有授权配置；提示词不包含密钥、私有路径和未同意公开的参考图。

## 检查与保存

逐图看身份、服装、情绪、边缘和留白，核对矩阵路径。PNG 解码通过不等于画质通过；测试夹具不能进入用户成品。

生成提示词、工具与确知的模型信息放包外，原始图集放包外，最终 PNG 复制进源包。网站可另导出压缩 WebP，包内媒体仍遵守当前客户端协议。
