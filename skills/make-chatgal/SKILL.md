# ChatGal 内容包创作

把用户的角色与故事做成可维护的源目录；素材和运行时验证齐全后交付可导入的 `.chatgal`。尊重题材、规模和风格，三幕循环只是可选模板。

## 能力与目标版本

找到用户指定的 ChatGal 工程。没有工程时可在任务目录检出 [主项目](https://github.com/RongShangs/ChatGal)，不根据版本名称猜协议。运行：

```text
python scripts/upstream.py check --project <ChatGal目录>
```

读取 `compatibility.lock.json`。代码、模型、校验器和渲染器优先于旧文档。离线且无工程时只能按锁定基线创作，明确目标客户端未验证。有差异时读 [兼容与维护](references/compatibility.md)，审阅变动再使用相关能力；不猜新字段，也不因无关变动丢弃已有内容。

枚举当前 agent 实际可调用的图像生成/编辑工具或已授权服务。模型名字、能看图、浏览器、图片搜索和 Pillow 都不等于能生图。

| 条件 | 动作 |
| --- | --- |
| 有可用、已授权生图工具 | 正常调用生成所需素材，检查参考形象、透明度、边缘和一致性；不要只交提示词代替执行，遵守对应工具要求。 |
| 没有工具或工具不可用 | 继续完成故事和 JSON，交付资源清单、逐图提示词与待补路径；可用用户授权的现成图片，不造占位图冒充成品。 |
| 只缺部分素材 | 保留有效结果，只补缺项。 |

失败如实记录，不静默换服务、不索要聊天中的密钥、不反复重试。详见 [素材流程](references/artwork.md)。

## 创作

1. 简要规划角色、服装状态×情绪、情景、事件、变量、分支和回归路径。只追问影响正确性且不能合理推断的信息。
2. 按需读 [内容格式与叙事](references/authoring.md)：支持多角色、入场改值、离场结算、条件和等概率出口、图文事件及事件选择题。无出口的停留情景可以有意保留，否则补出口并检查可达性。
3. 基础人格写 `character.json.prompt`，当下地点/时间/情境写 `scenePrompt`，逐变量取证标准写 `settlement[].prompt`。不让聊天文本直接改数值或自行跨幕。
4. 源包和创作附件分开：`pack/` 只放运行文件；提示词、计划、原始图集和报告放旁边。可用模板起步，之后按用户需求改写：

   ```text
   python scripts/init_pack.py --output <新工作目录> --brief <brief.json> --template daily --image-mode prompts
   ```

   `daily` 是三幕循环，`branching` 另示范随机情景、条件分支、事件和玩家选择。brief 示例在 `assets/example-brief.json`。有生图工具用 `--image-mode generate` 并随后实际调用；脚本本身不生图。
5. 完成全部 `states × emotions`，按实际人物边界裁切图集，检查头发、耳朵、手脚和尾巴；统一画布、比例与脚底位置。可用 `scripts/crop_sprites.py` 做明确边界框的机械裁切。
6. 模型、记忆、显示、字体或语音需求见 [设置与运行能力](references/settings.md)。这些属于应用设置，输出不含密钥的包外建议，不能写成包内字段；用户未要求时不改配置或存档。

## 校验和交付

```text
python scripts/build_pack.py --project <ChatGal目录> --source <工作目录/pack> --output <成品.chatgal>
```

工具核对版本指纹、媒体和未知顶层字段，再调用主项目同一份 `PackageLoader + PackageValidator`；通过后生成可复现 ZIP、解包回验和旁置报告。Dart/依赖不可用时不能声称已通过运行时校验。

- 第三方包保持 `packageId`，内容更新提高纯数字 `version`；它不等于应用版本。内置包更新才同步客户端常量与重建工具。
- 无生图能力也交付全部可完成的文本和逐图提示词，但缺图不能称可导入成品。需归档时用 `--draft` 生成 `.draft.zip`，不伪装成 `.chatgal`。
- 有分支、天数和结算时测试真实路径、阈值、每个选择与无证据行为；结构通过不代表剧情、画质或真实模型体验已通过。
- 交付源目录、成品/草稿状态、素材/提示词位置、目标应用版本和提交、实际验证及缺项。上架工坊、上传或部署只在用户明确要求时执行。

## 新能力

当前 UI 转场和云端朗读不等于包内动画、BGM 或音效。发现主项目新增能力时，沿兼容参考更新能力表、格式说明、资源计划、打包规则、示例和测试，验证后更新锁定基线；不能只改版本号或把未支持字段写进包。
